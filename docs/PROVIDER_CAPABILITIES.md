# 接入能力矩阵与验证门槛

核对日期：2026-10-27。此次只读取公开文档，没有登录供应商、索取或使用用户密钥，也没有调用真实发布、下单或付款。

证据等级：**文档支持**表示公开文档描述了能力；**说明级**只有官网概述；**不支持**表示对应文档明确限制；**未确认**表示本次没有足够证据。只有完成目标主体、账号和应用范围的真实联调，才能标为**实测通过**。本表没有任何“实测通过”项。

## 1. 候选对照

| 能力 | 蚁小二开放平台 | ALQQ 公开 API | 本产品处理 |
| --- | --- | --- | --- |
| 账号列表及授权状态 | 说明级 | 文档支持读取 | 保留连接与用户归属，不等于支持绑定 |
| API 内发起账号绑定、重新登录、解绑 | 抖音具体流程未确认 | 不支持，通过其界面处理 | 显示真实跳转流程，不做假绑定 |
| 抖音视频发布 | 内容发布为说明级，抖音参数需拿清单 | 文档支持 | 接口预检及真实作品回收仍需联调 |
| 完全不依赖额外执行节点的视频云发布 | 未确认 | 不适用其普通 web 视频路径；需 desktop 或符合条件的 edge | 采购或用户节点部署必须纳入成本与可用性 |
| 可下载 URL 直接作为视频源 | 未确认 | 当前视频 API 使用执行端本地文件 | 需要素材下发通道，不能只接对象存储 URL 就宣称完成 |
| 发布状态、逐账号结果 | 说明级 | 文档支持 | submitted、completed 和作品可见性分别处理 |
| 账号/作品分析数据 | 数据回收为说明级，指标未确认 | 完整指标分析覆盖未确认 | 发布日志不等于账号分析报表 |
| 发布结果 webhook | 未确认 | 文档支持，需按签名和事件约定处理 | 回调可能重复或乱序，仍需补偿查询 |
| DOU+ 下单、付款、停止和报表 | 未确认 | 本次公开发布文档中未确认 | 默认关闭真实投流，不以发布能力推断 |
| 商品或团购挂载、原作品补挂 | 未确认 | 未确认 | 独立能力，不将 POI 定位等同团购购买入口 |
| 个人主体接入和签约 | 未确认 | 未确认 | 供应商明确接受后才能商业接入 |
| 为自己的付费会员提供服务 | 未确认 | 未确认 | 自用 API 密钥不自动具有多用户服务许可 |
| 跨供应商账号、作品 ID 转换 | 未确认 | 未确认 | 无可验证映射时不能连接发布与投流 |

资料来源：[蚁小二开放平台](https://open.yxiaoer.cn/)、[ALQQ API 文档](https://www.alqq.cn/api-docs)。蚁小二页面直接抓取超时，使用同站搜索索引核对公开概述，因此证据仅为说明级；没有依赖其他厂商的对比营销文章确认其能力。

## 2. 官方接口事实与推论边界

- 抖音有需要申请权限、用户授权的创建视频接口，创建后还有审核；是否能在本项目使用仍未确认。[官方视频接口](https://partner.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/video-create)
- 巨量引擎公开 DOU+ 订单查询能力；查询接口存在并不能证明候选服务商具有下单、付款或停止权限。本次仅核对了查询文档中的状态和金额口径。[官方订单查询](https://open.oceanengine.com/labels/7/docs/1771736421276680)
- 多账号内容管理必须考虑平台的同质化限制，原创素材本身不等于可以无限重复群发。[平台使用规范](https://partner.open-douyin.com/docs/resource/zh-CN/dop/operation-standard/platform-capabilities/usage-spec/)

## 3. 联调准入清单

| 编号 | 必需证据 | 未通过时 |
| --- | --- | --- |
| G1 主体与使用范围 | 接受个人的书面条件；是否允许产品集成、付费会员及多租户使用 | 不开放商业用户真实接入 |
| G2 账号归属 | 本产品用户与供应商用户、账号及授权的归属链；绑定、撤销、失效和数据删除约定 | 不允许按任意账号 ID 导入 |
| G3 发布闭环 | 两个自有账号分别使用原创内容，取得实际作品链接、状态及重复请求行为证据 | 只开放演示或真实可完成的辅助流程 |
| G4 分析数据 | 指标权限、定义、时间区间、分页、历史范围、延迟和修订机制 | 缺失指标保持缺失，不上线虚假图表 |
| G5 投流闭环 | 可投作品、资金账户、目标、下单、付款、审核、查询、停止及对账的逐项证据 | 按能力禁用或明确人工步骤，不宣称全自动 |
| G6 写入可靠性 | 持久幂等期限、请求查询、超时和重复回调语义、跨日与追加行为 | 未决请求停止重试，由人工核验 |
| G7 标识映射 | 发布侧账号/作品与投流侧的可验证映射及授权 | 不发起真实投流 |
| G8 运行与成本 | 限流、并发、节点部署、费用、失败收费、服务支持和退出迁移 | 不定商业配额和售价 |

真实投流验证需要明确的账号、作品、目标、资金账户和预算后再执行。本文不申请额外授权，也不因建立清单就标记真实联调完成。

## 4. 下一步取证表模板

每次验证记录：供应商 / 应用与账号范围 / 文档版本 / 环境 / 测试时间 / 操作者 / 请求键 / 脱敏外部任务 ID / 预期 / 实际 / 查询或回调证据 / 费用 / 结论 / 限制。

禁止记录密钥、完整授权码、Cookie 或密码。生产环境的“在线调试”可能真的发布或扣费，不能把它当作沙箱。接入方只提供桌面执行时，须实际验证节点离线、文件不存在和用户退出客户端的表现。
