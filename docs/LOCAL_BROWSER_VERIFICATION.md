# 0.11 · 本机浏览器助手验证

## 新增功能：分周期作品与粉丝分析

已实现作品与粉丝两个分析面板，各自支持「昨天」「近 7 天」「近 30 天」。可以分别同步所选周期，或顺序同步全部 6 个周期；部分周期失败时保留已成功记录并展示失败原因。

作品分析展示投稿、播放、点赞、评论、分享的期间合计、可切换指标的每日趋势和全量日明细。比率和平均播放时长保持每日口径，不用简单平均生成期间指标。

粉丝分析从粉丝区域的官方导出读取总粉丝量、粉丝净增、吸粉量、脱粉量和回访粉丝量。总粉丝量取报表最后一天作为期末值，净增、吸粉、脱粉求期间合计；回访粉丝仅展示最近一天，不将每日人数相加当作期间去重人数。

各账号备注、分析类型和周期的结果独立保存在本机 `analyses.json`，切换周期查看已保存记录；界面同时展示实际导出日期与同步时间。缺失数据不按 0 处理，导出天数不匹配或日期不连续时不覆盖旧记录。

**按用户要求，本轮只实现功能，未执行新增周期的真实取数验证、自动化测试或构建验收。**下文的 30 天真实对照是此前版本的验证结果，不代表本轮所有新周期已经验收。

后续近 7 天同步故障排查：2026-10-27 已分别从助手接口和矩阵流页面同步作品、粉丝近 7 天报表，均返回 2026-10-20 至 2026-10-26 的 7 天记录。修正刷新后账号备注清空的问题，并为缺少登录、备注或账号确认的禁用状态提供明确提示。此排查没有验证昨天和粉丝近 30 天。

## 使用

需要 Windows 上已安装 Microsoft Edge，以及项目 Node.js 依赖。

分别启动：

```powershell
npm run dev
npm run assistant
```

进入 [本机助手](http://127.0.0.1:3000/assistant)。首页和演示账号管理页也提供入口。

1. 点击「打开登录窗口」，在独立 Edge 中自行扫码。该窗口使用项目专用浏览器配置，不读取 Codex 或用户默认浏览器的 Cookie。
2. 点击「打开数据表现页」。填写账号备注，并确认当前浏览器登录的是要读取的自有账号。备注是用户自填，当前未自动核实抖音账号唯一标识。
3. 可先点击「读取当前页面」查看能够准确识别的可见指标；不会从趋势图猜测每日数据。
4. 选择日期及短视频指标。需要与本次参考表比较时，选择「作品近 30 天」。日期最终以官方导出文件为准。
5. 点击「自动导出并同步」。助手定位作品报表区域中的官方导出按钮，不选择粉丝报表，也不触发发布或投流。
6. 可上传参考 Excel，查看日期交集、逐项一致数量和差异明细。完整日期与全部指标一致才显示完整匹配；没有数据或没有交集不能显示成功。

本机助手独立于 Web 服务。浏览器关闭后可从工作台重新打开；会话过期或平台出现安全验证时，需用户自行处理。停止 `npm run assistant` 可结束助手。当前单账号专用浏览器配置不提供多账号切换。

## 指标和口径

支持日期及以下 9 项：投稿量、总播放量、总点赞量、总分享量、总评论量、5秒完播率、2秒跳出率、封面点击率、平均播放时长。

- 百分比转换为比例、时长转换为秒，显示时恢复单位。
- 保留负数计数与缺失值，`-` 不转换为 0。
- 日报中的比率和平均时长不直接做算术平均；本版按日展示。
- 拒绝重复日期、缺少必要表头、超出范围的百分比和含公式的指标表。
- 参考表、官方导出和页面可见表格分别标记来源；页面汇总值不与每日明细混用。
- 参考 Excel 不包含账号 ID，无法仅凭该文件自动证明账号归属。

## 本机边界

助手只监听 `127.0.0.1:37211`（可用 `MATRIX_ASSISTANT_PORT` 调整），Web 桥接仅接受 localhost/127.0.0.1 同源请求。助手每次启动生成配对密钥，密钥只保存在本机，不返回给浏览器前端；未配对请求、外部 Origin 和错误 Host 被拒绝。

浏览器登录态留在专用 Edge 配置目录，不通过接口导出 Cookie、密码或授权令牌，不发送给第三方数据服务。页面读取与导航只针对 `creator.douyin.com`，不提供任意 URL、任意脚本或任意本地路径执行接口。

这是本机验证工具，不可直接作为公网多租户服务部署。尚未接入会员、真实账号唯一标识校验、多账号配置管理、无人值守调度及长期故障恢复。真实数据独立于原演示工作台保存和展示。
